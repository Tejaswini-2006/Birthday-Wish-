 Happy Birthday Virali

A simple and colorful birthday greeting webpage created for Virali. The page displays "Happy Birthday" wishes in multiple Indian languages using a clean responsive grid layout.

Features

🎂 Personalized birthday greeting for Virali
🌍 Birthday wishes in 20 language/variant entries
📱 Responsive grid layout
🎨 Warm birthday-themed colors
🖱️ Hover animation on greeting cards
✨ Rounded cards with dashed borders and soft shadows
🔤 Google Fonts for attractive typography
🌐 Languages Included

Hindi, Tamil, Telugu, Malayalam, Bengali, Marathi, Gujarati, Punjabi, Kannada, Odia, Assamese, Urdu, Nepali, Sanskrit, Sindhi, Rajasthani, Konkani, Bodo, Kashmiri, and Hindi (colloquial).

🛠️ Technologies Used

HTML5 – Page structure and greeting content
CSS3 – Styling, responsive grid, colors, borders, and hover effects
Google Fonts – Poppins and additional imported font families

📁 Project Structure

Happy-Birthday-Virali/

▶️ How to Run

No server or database is required.
Keep index.html and style.css in the same folder.
Open index.html in any modern web browser.
You can also use VS Code with Live Server.

🎨 Design

The webpage uses a soft cream background, peach birthday card, coral borders, pink heading text, white greeting boxes, and a responsive CSS Grid layout. Each greeting slightly enlarges when the mouse hovers over it.

🔄 Page Flow

Open index.html
      ↓
Birthday Card for Virali
      ↓
"Happy Birthday, Virali" Heading
      ↓
Responsive Grid of Greetings
      ↓
Hover over a greeting for animation

📌 Notes

This is a static frontend project.
No JavaScript, backend, database, login system, or form submission is used.
Google Fonts are loaded from the internet.
All birthday greetings are directly written in the HTML file.
